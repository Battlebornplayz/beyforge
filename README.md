# BeyForge

Design custom Beyblade X and Burst Beys, export them for 3D printing, and battle them.

- **Play on PC or phone:** https://battlebornplayz.github.io/beyforge/
- **Windows app:** [Download BeyForge-Setup.exe](https://github.com/Battlebornplayz/beyforge/releases/latest/download/BeyForge-Setup.exe) — updates itself. Windows may warn the first time: More info → Run anyway.
- **Android app:** [Download BeyForge.apk](https://github.com/Battlebornplayz/beyforge/releases/latest/download/BeyForge.apk), open it, and allow installing from your browser when Android asks.

On Android you can also open the web link in Chrome and tap **Install app** — it updates itself every time a new version is pushed.
